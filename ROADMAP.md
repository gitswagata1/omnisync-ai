# Roadmap

## Vision

Make OmniSync the default coordination layer for industrial teams that already live in WhatsApp.

## Milestones

### Now

- [ ] Public benchmark for response-evaluation accuracy
- [ ] Hardening: webhook signature checks, rate limits, audit exports
- [ ] One-command deployment guide for a first pilot

### Next

- [ ] Role-based executive digests
- [ ] Pluggable ERP and calendar connectors
- [ ] Evaluation harness for agent decisions

### Later

- [ ] Multi-tenant hosted offering
- [ ] On-premise model option for regulated customers
- [ ] Analytics on coordination delays

## Where this can go

| Direction | Idea |
| --------- | ---- |
| **Startup** | Pilot with two or three plants, then sell per-site subscriptions. |
| **Publication** | The README links a research paper and patent documents. Keep those artefacts in `research/` and `patents/` current and cited via CITATION.cff. |
