## Appendix: Objection Handling

**"WATI could add these features."** — Adding proactive scheduling, LLM loops, and cross-dept sync is a full platform rebuild, not a feature. Our 3 patents cover the core mechanisms.

**"WhatsApp could build this."** — Meta sells infrastructure; building vertical apps would alienate their BSP ecosystem. AWS didn't kill Datadog.

**"Only one pilot plant."** — That's what this round funds. Architecture is multi-tenant from day one. WhatsApp API handles 1,000 msg/sec.

**"LLM costs will eat margins."** — LLM is our largest COGS and it's falling fast. At scale, we fine-tune open-source models. Core SaaS has near-zero marginal cost.
